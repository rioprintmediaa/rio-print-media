Upload a layered Photoshop file. Each layer is read out
individually — image, text, and shape layers are told apart
automatically — so you can correct the Cyan, Magenta & Yellow
ink channels on each one independently before positive film.

⚠️ CorelDRAW (.cdr) files can't be read directly — no browser tool can parse that closed format. Export/save as .psd from CorelDRAW first, then open that file here.
⚠️ This PSD is saved in CMYK mode, which this tool's reader library cannot parse (RGB and Grayscale only). In Photoshop: Image → Mode → RGB Color, then flatten and save again before uploading here — or use "Export → Save as" to a flattened PNG and use the CMY Proof tool instead.
